# Jumper на путоне

Игра в стиле Doodle Jump, написанная на путоне


---------------
## Запуск игры
1. Склонируйте и скачайте репозиторий:
    ```bash
    git clone https://github.com/hugtarr/jumper.git
    ```
2. Откройте терминал в папке с проектом
3. Выполните команду:
    ```bash
    git main.py
    ```
4. Наслаждайтесь этим шедевром!
----------------
## Особенности:
- Полностью основан на Python 3.14.3
- Основной движок - 'pygame-ce'
- Больше не придумал
